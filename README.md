# BFT PED 工程設備箱管理系統

用於伺服器系統廠／板廠，由 PED 產品工程部管理工程設備箱，讓產線依站別（Fixture）申請整箱借用，並完成簽核、領用、歸還與零件檢查。

支援繁體中文／English、深色／淺色、三層角色權限、儀錶板、操作紀錄及 CSV 匯出。箱內零件可登錄 CPU、DIMM、Cable、U.2、Heatsink 等品項的料號、序號與數量。

## 本機使用

安裝 Node.js **22.13 以上**（建議 24），下載並解壓縮專案，於專案目錄執行：

```powershell
npm start
```

Windows 也可雙擊 **啟動設備管理.cmd**。首次啟動會安裝套件、建置、建立資料庫，再開啟 [本機網站](http://127.0.0.1:3000)。首次下載套件需要網路。

第一次使用請自行建立管理員；沒有預設帳密。若要空白開始，請不要勾選載入範例資料。密碼長度為 6–128 字元。

```powershell
npm run stop:local
npm run backup:local
```

備份前須先停止系統。資料位於 `data/`，不會隨 Git 上傳；從 GitHub 下載的專案會建立全新的本機資料。預設僅監聽本機 `127.0.0.1`，資料與原雲端網站各自獨立。

## 成員權限

| 角色 | 主要權限 |
| --- | --- |
| 產線操作人員 | 提出、查看與取消自己的申請 |
| PED 工程人員 | 簽核同部門其他人的申請；管理設備箱與零件、維護／停用、領用歸還及檢查紀錄 |
| PED 系統管理員 | 全部管理權限、成員與系統設定、跨部門簽核 |

所有角色均不能簽核自己的申請。伺服器會檢查權限、設備時段重疊與零件點交完整性。

系統角色為產線操作人員、PED 工程人員與 PED 系統管理員。升級時，原「PED 設備箱管理員」帳號會轉為「PED 工程人員」，取得同部門其他人申請的簽核權；保留帳號、密碼、部門與歷史紀錄，該帳號需重新登入。
